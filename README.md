# 🧪 QA Automation Projects by Gopichand Pawar

This repository showcases multiple automation testing projects built using **Selenium WebDriver, Python, PyTest, Postman, SQL, and Playwright (basic)**.  
Each project demonstrates practical QA workflows including functional, regression, API, UI, and database testing.

---

## 📂 Projects

### 1. [Selenium-Pytest-Automation](https://github.com/gopichandpawar/Selenium-Pytest-Automation)
- Automated login, checkout, and order workflows
- Tools: Selenium, Python, PyTest, POM
- Features: HTML reports, screenshots, SQL validation

### 2. [OrangeHRM Automation](https://github.com/gopichandpawar/OrangeHRM-Automation)
- Automated employee management workflows (Add, Edit, Delete, Leave Approval)
- Tools: Selenium, Python, PyTest, POM
- Features: Modular scripts, reusable components

### 3. [Insurance Portal Automation](https://github.com/gopichandpawar/Insurance-Portal-Automation)
- Automated user registration, quote form, premium calculation, claims
- Tools: Selenium, Python, Postman, SQL
- Features: API testing + DB validation

### 4. [Online Ticket Booking Automation](https://github.com/gopichandpawar/Online-Ticket-Booking-Automation)
- Automated bus booking workflows (login, search, seat selection, payment, cancellation, refund)
- Tools: Selenium, Python, PyTest, POM, SQL
- Features: End-to-end workflow validation, defect tracking with JIRA

---

## 🛠️ Tech Stack
- **Languages:** Python, SQL

- **Testing Tools:** Postman, JIRA
